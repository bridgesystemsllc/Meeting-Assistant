# Hero media attribution

Participant and attendee avatars in the §5.3a mockup use **initials**, not photographs. The `avatars/` folder is empty on purpose.

No Unsplash, jiro, or other third-party image hotlinks are used. If photographic avatars are added later they must be self-hosted here (≤ 40 KB webp each) with photographer name and source URL listed in this file.
